# Detailed basemap

`style.json` is the OpenFreeMap Dark style retrieved from https://tiles.openfreemap.org/styles/dark. JSON formatting is normalized. SkyPulse applies dark petrol-blue water, muted green-gray land, subdued boundaries, and readable labels at runtime. A subtle blue atmosphere separates the globe from the dark background and fades out on closer zoom. It prefers English place names when available.

The globe's continents, oceans and country boundaries come from `world-base.png`, a bundled 2048 × 2048 Web Mercator image. Its image source loads once and remains resident while rotating and zooming; it does not use the vector tile cache. The PNG is about 600 KB on disk and 16 MiB as uncompressed RGBA pixels, excluding renderer overhead. It remains visible if the external provider is unavailable.

At zoom 4 and above, detailed vector surfaces load from https://tiles.openfreemap.org. The world image covers incomplete surfaces and fades out once those tiles are ready. During a slow close-up load this base is less sharp than the detailed map. Geographic labels remain separate and may load as the camera moves. Label filters do not invalidate the surface cache. No credentials or SkyPulse session cookies are sent to the provider.

Sources and attribution: [Natural Earth](https://www.naturalearthdata.com/), [OpenFreeMap](https://openfreemap.org/), [OpenMapTiles](https://openmaptiles.org/), and [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Attribution remains visible in the map. Upstream license notices are included alongside this file.

To change map hosting, update `style.json` source/glyph/sprite URLs and the explicit map host allowlist in `apps/web/nginx.conf`. Do not place private API keys in this public asset.

To regenerate the global image, download Natural Earth v5.1.2 [land](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_land.geojson) and [country boundary lines](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_admin_0_boundary_lines_land.geojson) into an input directory as `land.geojson` and `boundaries.geojson`. These datasets are [public domain](https://www.naturalearthdata.com/about/terms-of-use/); the scale is 1:10 million, not 10-meter resolution. From the repository root run `node scripts/build-world-map.mjs <input-directory>` with Playwright Chromium installed, or set `BROWSER_CHANNEL=msedge` to use an installed Edge. The generator applies the SkyPulse palette and projects the geographic coordinates into the image; the original GeoJSON files are not shipped to browsers.
